# معركة العقول — Battle of the Minds (v40)

لعبة أسئلة ومسابقات عربية متعددة اللاعبين (ويب + جوال) على Firebase.
**الإصدار الحالي: v40 — كل اللاعبين ظاهرون في تجهيز المباراة بلا تمرير (على أساس v39 + v38 الأمنية).**
اللغات الأخرى جاهزة في القواميس وتُفعَّل مستقبلًا من `translations.js → OFFERED_LANGS`.

## بنية الحزمة

```
1-game/      كود اللاعب (index.html + الوحدات + privacy.html + terms.html)
2-admin/     لوحة الإدارة (admin/)
5-functions/ دوال Firebase + دليل-النشر-والمصادقة.md + دليل-الترقية-الأمنية.md
CHANGELOG-V32.md  سجل الإصدارات من v31 حتى v38
firestore.rules   قواعد الأمان المشددة v38 (انسخها إلى Console → Firestore → Rules)
```

## النشر (GitHub Pages)

1. انسخ محتوى `1-game/` إلى مجلد اللعبة في المستودع (حيث `index.html` الحالي).
2. انسخ `2-admin/admin/` إلى مجلد اللوحة (يجب أن تبقى بجانب اللعبة لأنها تستورد `../firebase-config.js`).
3. انشر، ثم افتح اللعبة واللوحة وتأكد من الكونسول.

## بعد النشر مباشرة (مهم)

1. **القواعد**: انسخ `firestore.rules` إلى Firebase Console → Firestore → Rules → Publish.
2. اقرأ `5-functions/دليل-الترقية-الأمنية.md` — فيه خطوات App Check وخطة Blaze وقرار زر شاشة الحظر.

## التوثيق

- سجل التغييرات الكامل: `CHANGELOG-V32.md` (آخر قسم = v38).
- قواعد الأمان وشرح كل قاعدة: `firestore.rules` (معلّق بالعربية).

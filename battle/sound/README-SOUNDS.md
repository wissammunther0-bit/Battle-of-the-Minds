# 🔊 مجلد الأصوات — sound/

ضع ملفات الأصوات الخمسة في هذا المجلد **بنفس الأسماء التالية حرفيًا**:

| الملف | الاستخدام | متى يعمل |
|---|---|---|
| `sound1.mp3` | صوت النقر (اللمس) | عند الضغط على أي زر في التطبيق |
| `sound2.mp3` | علامتا الصح ✓ والخطأ ✗ | عند ظهور علامات النتيجة بين الأسئلة |
| `sound3.mp3` | الإجابة الصحيحة | عندما يجيب اللاعب إجابة صحيحة |
| `sound4.mp3` | الإجابة الخاطئة | عندما يجيب اللاعب إجابة خاطئة |
| `sound5.mp3` | موسيقى الخلفية | تعمل في الخلفية بشكل دائم (تكرار تلقائي) |

## ملاحظات مهمة

1. **الصيغة المقبولة:** `.mp3` (مفضّلة) — ويُدعم أيضًا `.ogg` / `.wav` / `.m4a`
   بنفس الاسم (مثال: `sound5.ogg`).
2. **حجم الملف:** يُفضّل ألا يتجاوز كل ملف **500KB**، وخاصة `sound5.mp3`
   (الخلفية) — قصّه إلى 30–60 ثانية وسيكرره النظام تلقائيًا بسلاسة.
3. **التحميل:** يُحمَّل كل صوت **مرة واحدة فقط** عند أول لمسة للاعب ثم يُخزَّن
   في الذاكرة (WebAudio Buffers) — لا إعادة تنزيل أبدًا حتى بين الجولات.
4. **الخلفية التدريجية:** يبدأ صوت الخلفية من مستوى منخفض ويصعد تدريجيًا
   إلى مستواه الطبيعي خلال ~4 ثوانٍ (بعد منح المتصفح إذن التشغيل بأول لمسة).
5. **إذا حذفت صوتًا:** النظام يتجاوزه بصمت — لا أخطاء ولا توقف للعبة.

— أُنشئ هذا المجلد بناءً على طلب المطور (دفعة v11).

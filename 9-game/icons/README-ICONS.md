# 🎨 دليل أيقونات اللعبة — اقرأني قبل أن تضع أيقوناتك

## 💡 الفكرة ببساطة

هذا المجلد `icons/` مخصص **لأيقوناتك أنت**.

اللعبة تعمل الآن بأيقونات مدمجة (رسوم SVG داخل الكود) حتى لو لم تضع أي ملف هنا.
لكن إن أردت أيقوناتك الخاصة التي تحمّلها من الإنترنت:

1. حمّل الأيقونة التي تعجبك من أي موقع (Flaticon / Icons8 / SVG Repo / Lucide...).
2. **غيّر اسمها** إلى الاسم المطلوب من الجدول بالأسفل **بالضبط** (حساس لحالة الأحرف).
3. ضعها في هذا المجلد `icons/`.
4. حدّث الصفحة — انتهى! اللعبة تفحص هذا المجلد عند كل تشغيل وتستخدم أيقونتك تلقائيًا.

## 📏 القواعد المهمة

| القاعدة | التفصيل |
|---|---|
| **الصيغ المقبولة** | `SVG` أو `PNG` — ضع ملفًا واحدًا فقط لكل أيقونة |
| **أولوية الصيغ** | SVG أولًا ثم PNG، باستثناء `gems` و`tokens` اللتين تستخدمان ملفات PNG الحالية مباشرة |
| **الاسم** | يجب أن يطابق اسم الجدول حرفيًا، مثل `home.svg` وليس `Home.svg` أو `home (1).svg` |
| **المقاس المناسب** | SVG بأي مقاس، أو PNG مربع بمقاس 96×96 أو 128×128 (خلفية شفافة) |
| **اللون** | ملف SVG بلون `currentColor` يتلوّن مع ثيم اللعبة تلقائيًا. الأيقونة الملوّنة الثابتة (PNG أو SVG بألوان ثابتة) تظهر كما هي |
| **التحديث** | الملفات تُفحص عند كل تشغيل — بديل أي ملف وحدّث الصفحة فقط، بلا أي تعديل كود |

## ✅ مثال عملي

تريد تغيير أيقونة السجل:

1. حمّل أيقونة ساعة من موقع أيقونات بصيغة SVG.
2. غيّر اسم الملف من `clock-icon-by-name.svg` إلى **`clock.svg`**.
3. ضعه في مجلد `icons/` بجانب الملف القديم (سيحل محله).
4. حدّث صفحة اللعبة — ستظهر أيقونتك بدل أيقونة السجل الافتراضية.

> ملاحظة: `gems` و`tokens` يستخدمان ملفي PNG الموجودين مباشرة؛ استبدل
> `gems.png` أو `tokens.png` لتغييرهما. بقية الأيقونات تستخدم SVG أولًا،
> ثم PNG إذا لم يوجد ملف SVG مطابق.

> 📝 ملاحظة: الملفات الموجودة حاليًا في هذا المجلد هي الأيقونات المدمجة البادئة —
> استبدلها بحرية، واللعبة لن تتعطل أبدًا: أي أيقونة لم تجد ملفها تعود تلقائيًا للمدمجة.

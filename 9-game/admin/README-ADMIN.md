# 🛡️ دليل صفحة الأدمن (Admin Console) — معركة العقول (Battle of the Minds)

## 🚨 مكان الإدارة الصحيح (مهم — يمنع أخطاء 404)

لوحة الإدارة **تعيش داخل مجلد اللعبة** لأنها تشاركها ملفات مشتركة
(`firebase-config.js` و`game/economy.js` و`ui/icons.js`):

```
مجلد-اللعبة/
├── index.html          ← اللعبة
├── firebase-config.js
├── game/  ·  ui/  ·  ...
└── admin/              ← انسخ مجلد admin هنا (بجانب index.html)
    └── index.html      ← اللوحة: https://موقعك.com/admin/
```

- ✅ **الصحيح:** انسخ مجلد `2-admin/admin/` إلى **داخل** مجلد اللعبة (بجانب `index.html`) ثم افتح `/admin/`.
- ❌ **الخطأ الشائع:** فتح اللوحة من مجلد `2-admin/` وحده (بعيدًا عن اللعبة) — ستحصل على
  `404` لملفات `firebase-config.js` / `game/economy.js` / `ui/icons.js` مثل:
  `GET .../2-admin/firebase-config.js net::ERR_ABORTED 404`.
- 🔧 **إن أردت إبقاء اللوحة في مجلد مستقل** (مثل اختبارك على GitHub): انسخ الملفات الثلاثة
  المشتركة بجانبها بنفس البنية — `firebase-config.js` + `game/economy.js` + `ui/icons.js`.

## 📍 الوصول
الصفحة مستقلة تماماً عن اللعبة ولا يراها اللاعبون أبداً:

```
https://موقعك.com/admin/
```

مثال: إذا كانت اللعبة على `https://mygame.web.app` تصبح اللوحة:
`https://mygame.web.app/admin/`
(لا يوجد أي رابط للوحة داخل اللعبة — العنوان سرّيك.)

## ⚙️ الإعداد لمرة واحدة (5 دقائق)

### 1) فعّل تسجيل الدخول بالبريد في Firebase
Firebase Console → Authentication → Sign-in method → **Email/Password** → Enable.

### 2) أنشئ حسابك كمطور
Firebase Console → Authentication → Users → **Add user**
- البريد: مثلاً `dev@mygame.com`
- كلمة المرور: قوية

### 3) انسخ UID حسابك (يظهر في قائمة Users)

### 4) أضف نفسك لقائمة الأدمن
Firebase Console → Firestore Database → Start collection:
- Collection ID: **`admins`**
- Document ID: **الصق UID هنا**
- لا حاجة لحقول داخل الوثيقة (أو أضف حقل `name` اختيارياً)

### 5) انشر قواعد الأمان
Firebase Console → Firestore → Rules → الصق محتوى ملف `firestore.rules` المرفق → Publish.
(بدون هذه القواعد لن تعمل عمليات الحظر/الحذف، ولن تكون البيانات محمية.)

### 6) فعّل Google (إن لم يكن مفعلاً)
Authentication → Sign-in method → **Google** → Enable.
(مطلوب لزر "المتابعة بحساب Google" في الملف الشخصي.)

## 🔐 ملاحظات أمنية
- الصفحة تتطلب **حساباً موجوداً في مجموعة `admins`** — أي حساب آخر يُطرد فوراً.
- لا تنشر رابط اللوحة في أي مكان. ويمكنك تغيير اسم المجلد `admin` لأي اسم سري قبل الرفع (مثل `dev-console-9x`).
- الحظر يحفظ في `players/{uid}.banned` — اللاعب المحظور يرى شاشة حظر + زر التواصل مع الدعم.
- الحذف يكتب "حجر أمني" في `banned/{uid}` حتى لا يستطيع اللاعب إعادة إنشاء حسابه.

## 💡 ملاحظات تقنية
- عناصر المتجر تُقرأ من مجموعة `storeItems` وتُدمج فوق الافتراضيات — نفس `id` يستبدل الافتراضي.
- شارة "جديد المتجر" تتحكم بها وثيقة `storeMeta/version` — تُرفع تلقائياً مع كل نشر/إخفاء/حذف.
- ردود الدعم تُكتب في `supportTickets/{id}.replies` — اللاعب يراها في نافذة الدعم.
- أسئلة الأدمن تُخزن في مجموعة `questions` بحقل `active: true` ويحملها المحرك مباشرة.

### آلية اقتصاد v11
- كل **10 علامات انتصار = 1 جوهرة**، وكل **100 جوهرة = 1 جائزة ذكاء** 🧠
- الجوائز تُستبدل بجوائز الذكاء في شريط الرئيسية (يتحرك تلقائيًا كل 3 ثوانٍ)
- استلام جائزة = **تصفير كل عدّادات الشروط** — لا يمكن ركوب نفس الاستخدام لجائزة أخرى
